# Experiment log

Record every model experiment here or in a structured CSV/JSON alongside it.

| Run ID | Date | Modality | Label/target | Features | Model | Group split | Metrics | Artifact path | Notes |
|---|---|---|---|---|---|---|---|---|---|

Rules:
- Record all attempted experiments, not only the best result.
- Record the exact participant grouping and fold strategy.
- Record preprocessing fitted on training data only.
- Do not report a score without naming the held-out evaluation design.
